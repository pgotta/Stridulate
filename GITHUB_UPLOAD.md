# Uploading this project to GitHub

This ZIP is prepared as a repository root. Extract it before adding it to GitHub.

## GitHub Desktop

1. Extract the ZIP to a permanent folder.
2. In GitHub Desktop, choose **File → Add local repository**.
3. Select the extracted Stridulate folder.
4. If prompted, choose **Create a repository here**.
5. Review the files, make the first commit, and publish the repository.

The project already contains `.gitignore`, GitHub issue templates, pull-request guidance, and Android build workflows.

## Important status and licensing notes

- Keep the work-in-progress/proof-of-concept warning visible in `README.md`.
- The bundled model is research-only because its source pool includes noncommercial licenses.
- A source-code license has not yet been selected. Add one before calling the repository open source or accepting reusable contributions.
