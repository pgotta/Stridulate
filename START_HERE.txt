STRIDULATE v0.3 — PRE-RELEASE / RESEARCH BUILD
=============================================

Stridulate is still a very early beta/research build. It is not a finished field-identification product.
Expect false matches, No confident match results, and uneven performance outside the controlled Stage-J tests.

CURRENT DETECTOR
v0.3 uses frozen Stage J.1 / Perch 2.0 with 88 supported acoustic classes.
It is strongest when one supported insect is the dominant caller. Reliable simultaneous multi-insect
separation is not implemented yet and is deferred to Stage K.

BUILD / INSTALL
Read BUILD.md. For an existing field-test phone with saved Unknown WAVs, do NOT uninstall Stridulate
and do NOT clear app data. Use the supplied v0.3 Windows build/install package so it can perform an
in-place adb install -r update and stage the frozen runtime files safely.

MODEL RUNTIME
The large Perch ONNX model, frozen J.1 affine head, and calibration are intentionally not committed
inside the repository or APK. The Windows helper verifies and stages them into app-private storage.

PRIVACY
Classification runs locally. Unknown WAVs remain local unless the user explicitly shares or exports them.
