STRIDULATE v2.3.2 — WORK IN PROGRESS / PROOF OF CONCEPT
=========================================================

This repository is buildable Android source, but the classifier is not yet a dependable
field-identification product. Expect false matches and No confident match results.

QUICK BUILD
1. Open this repository in Android Studio.
2. Allow Gradle sync to finish.
3. Choose Build -> Build APK(s).
4. Install app\build\outputs\apk\debug\app-debug.apk.

GitHub Actions also verifies the model contract and builds a downloadable debug APK
after each push to main. Custom Windows .bat helpers are intentionally excluded from Git.

LOCATION / WEATHER
Optional context refreshes in the background every ten minutes. Pressing Record starts the
microphone immediately and never waits for location or weather.

MODEL LICENSE
The bundled epoch-19 model is research-only because its training pool includes
noncommercially licensed recordings.

Read README.md and PROJECT_STATUS.md before publishing or distributing the app.
