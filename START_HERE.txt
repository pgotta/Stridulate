STRIDULATE v2.3.2 — WORK IN PROGRESS / PROOF OF CONCEPT
=========================================================

This repository contains buildable Android source, but the classifier is not yet a dependable
field-identification product. Expect false matches and No confident match results.

BUILD
Read BUILD.md. On Windows, open the repository in Android Studio and use Build APK(s).
The public repository intentionally contains no .bat files.

LOCATION / WEATHER
Optional context refreshes in the background every ten minutes. Pressing Record starts the
microphone immediately and never waits for location or weather.

LICENSE
Original source code and project documentation use the MIT License.
The bundled epoch-19 model remains research-only because its training pool includes
noncommercially licensed recordings. See MODEL_AND_ASSET_LICENSES.md.
